# Hearsay Error Analysis: Baseline CoT vs Neuro-Symbolic

## Scope and Data Integrity

- Dataset: 94 Hearsay samples from `dataset/hearsay_predicates_breakdown.csv`.
- Baseline CoT files: DeepSeek, GPT OSS, Gemma all contain 94 rows and include `prediction`/`is_correct`.
- Neuro-Symbolic files: DeepSeek and Gemma contain 94 rows. GPT OSS file `pythen_openai.gpt-oss-120b.csv` contains 89 rows matching the 94-sample ground-truth index set.
- Missing GPT OSS Neuro-Symbolic sample IDs: [8, 46, 51, 65, 87]. These missing predictions are treated as `false` / `No` for final-label metrics and error annotation.
- Positive class for accuracy/precision/recall/F1: `Yes` = hearsay.
- Neuro-Symbolic prediction rule used here: `is_hearsay = (oral OR written OR non_verbal_assertive_conduct) AND is_out_of_court AND is_introduced_to_prove_truth`.
- Annotation status: E1/E2 are assigned by comparing extracted predicates with the ground-truth predicate sheet; E3 is assigned by substring validation of references; E4/E5 are heuristic labels from Baseline CoT final-label errors and should be manually confirmed before final submission.

## 2. Error Taxonomy

| Layer | Code | Error Category | Operational Definition Used in This Audit |
|--|--|--|--|
| LLM Extraction | E1 | Predicate Hallucination (False Positive) | Extracted JSON sets a predicate to `true` while the ground-truth predicate table marks it `false`. |
| LLM Extraction | E2 | Predicate Omission (False Negative) | Extracted JSON sets a predicate to `false` while the ground-truth predicate table marks it `true`; missing Neuro-Symbolic outputs imputed as `No` are also counted here when the ground truth is `Yes`. |
| LLM Extraction | E3 | Quote Mismatch / Invalid Reference | Extracted JSON sets a predicate to `true`, but `reference_texts` is absent, non-supportive, or not found in the fact pattern. |
| Baseline CoT | E4 | Over-conservatism Bias | Baseline predicts `No` for a `Yes` ground-truth sample; this captures false-negative CoT conservatism and should be manually confirmed from the reasoning text. |
| Baseline CoT | E5 | Logical Jump in CoT | Baseline predicts `Yes` for a `No` ground-truth sample; this captures free-form reasoning that jumps over at least one legal condition. |

## 5. Root Cause Diagnosis

### DeepSeek V4 Flash

- Baseline CoT: accuracy=0.745, precision=0.635, recall=0.976, F1=0.769.
- Neuro-Symbolic: accuracy=0.777, precision=0.679, recall=0.927, F1=0.784.
- Predicate extraction: precision=0.789, recall=0.851, slot accuracy=0.845.
- Error counts: E1=17, E2=4, E3=0, E4=1, E5=23.
- Key diagnosis: the symbolic rule improves or preserves final F1 by replacing free-form conclusion drift with deterministic composition of extracted predicates.

### GPT OSS 20B/120B

- Baseline CoT: accuracy=0.766, precision=0.744, recall=0.707, F1=0.725.
- Neuro-Symbolic: accuracy=0.819, precision=0.740, recall=0.902, F1=0.813.
- Predicate extraction: precision=0.775, recall=0.923, slot accuracy=0.858.
- Error counts: E1=13, E2=4, E3=0, E4=12, E5=10.
- Key diagnosis: the symbolic rule improves or preserves final F1 by replacing free-form conclusion drift with deterministic composition of extracted predicates.

### Gemma 4 31B

- Baseline CoT: accuracy=0.777, precision=0.667, recall=0.976, F1=0.792.
- Neuro-Symbolic: accuracy=0.840, precision=0.750, recall=0.951, F1=0.839.
- Predicate extraction: precision=0.873, recall=0.918, slot accuracy=0.911.
- Error counts: E1=13, E2=2, E3=0, E4=1, E5=20.
- Key diagnosis: Gemma has 1 cases where CoT was correct but PYTHEN became wrong after predicate extraction. These cases support the claim that the regression is caused by boundary predicate errors rather than the symbolic rule itself.

## 6. Case Studies

### Case Study: Sample #42

- Fact Pattern: "To prove that Alice suffered reputational harm, the fact that people were telling Bob that they had heard bad things about Alice."
- Ground Truth: hearsay = `Yes`
- Gemma 4 31B Baseline CoT prediction: `Yes`; Neuro-Symbolic prediction: `No`
- Gemma 4 31B extracted predicates: is_oral_assertion=True, is_written_assertion=False, is_non_verbal_assertive_conduct=False, is_out_of_court=True, is_introduced_to_prove_truth=False
- DeepSeek V4 Flash Baseline CoT prediction: `Yes`; Neuro-Symbolic prediction: `Yes`
- DeepSeek V4 Flash extracted predicates: is_oral_assertion=True, is_written_assertion=False, is_non_verbal_assertive_conduct=False, is_out_of_court=True, is_introduced_to_prove_truth=True
- GPT OSS 20B/120B Baseline CoT prediction: `No`; Neuro-Symbolic prediction: `No`
- GPT OSS 20B/120B extracted predicates: is_oral_assertion=True, is_written_assertion=False, is_non_verbal_assertive_conduct=False, is_out_of_court=True, is_introduced_to_prove_truth=False
- Gemma boundary predicate issue: FP=[]; FN=['is_introduced_to_prove_truth'].
- PYTHEN effect: because `is_hearsay` uses an `ALL` conjunction after detecting a statement, one omitted core predicate is sufficient to force the final result to `No`.
